04You have the last word

The agent marks each comment resolved with a note, over MCP or in the review file. You accept with R, or edit to reopen.

A review per branch, not per session.

Comments stay with the branch between runs and across worktrees, in one file inside the repository's .git. Switch branches with ⌘K without checking anything out; compare with any branch, tag or commit, with only the last commit, or with only the uncommitted changes.

Suggest the code, not a paraphrase of it.

A suggestion holds the replacement lines themselves. The agent is told to put them in as written, or to leave them and say why. Questions go out under their own heading, with the instruction to answer and change nothing.

The agent answers in the same file.

The instructions name the review file and each comment's id. With the diff-loop MCP server the agent calls resolve_comment; without it, it edits the file. Either way the window shows the mark and the note as soon as they are saved, and nothing is accepted until you say so.

Install

Download, open once, connect your agent.

01Download

Open the .dmg from the latest release and drag Diff Loop to Applications. Apple Silicon; no Intel or Windows build yet. Linux builds from source.

Download for macOS

02Allow it once

macOS will say it can't verify Diff Loop: the build is ad-hoc signed, not signed with an Apple Developer ID or notarized. Open it, dismiss the warning, then in System Settings › Privacy & Security click Open Anyway. Or clear the flag once:

xattr -dr com.apple.quarantine "/Applications/Diff Loop.app"

03Connect your agent · optional

The copied instructions work with any agent. For the round trip, build the MCP server (it needs Rust, through rustup; it isn't in the installer yet) and register it. Start the agent in the repository you are reviewing, on a branch: the server reads that branch's review.

cargo build --release -p diff-loop-mcp

FAQ

Frequently asked questions.

Is this an AI reviewer?

No. You review. The agent only reads your comments and marks what it dealt with, with a note.

Which agents does it work with?

Any agent you can paste text into: the review is plain Markdown. Claude Code, Codex and other MCP clients can also read and resolve the review through the diff-loop server.

Where does my code go?

Nowhere. Diff Loop runs git on your Mac and reads the results. There is no account, no server and nothing to sign in to.

Does it change my repository?

It never checks anything out. Its only writes are the review files, one per branch at .git/diff-loop/reviews/<branch>.json, shared by the repository's worktrees.

What does it cost?

Nothing. MIT license, source on GitHub, no paid tier.

Why does macOS refuse to open it?

The app is ad-hoc signed, not notarized. Allow it once under Privacy & Security, or build it from source. There is no auto-updater yet: each release is downloaded by hand.

Can I review from the keyboard?

Yes. J K move between files, C comments on the line, R resolves or accepts, ⌘ ⇧ C copies the review, ⌘ 2 splits the diff, ⌘ F finds in the file. Every shortcut is listed in the README.

Does it work with pull requests?

No. It reviews local branches and never reads or posts to GitHub. Open the pull request's branch in a worktree and review it there.
