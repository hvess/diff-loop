# 0001 — Front-end stack, and git through its command line

**Status:** accepted, 2026-10-13
**Affects:** AGENTS.md "Language & Platform"; open-tasks 2 (closed by ADR 0006); CI (`.github/workflows/ci.yml`)

## Context

AGENTS.md left the front end's framework unchosen. The first screens to
build are the "Agent Review" design (claude.ai/design project
`df71ed5c-a97b-4293-a1f7-f31eb6b93f9b`, file `Agent Review.dc.html`): a
diff viewer with line, range and suggested-code comments that are copied
to a coding agent as instructions. The core also needs a way to read git.

## Decision

1. **Tauri 2, with React 19, TypeScript and Vite** for the front end, in
   `app/` (Rust side in `app/src-tauri/`). The developer's call,
   2026-10-13: Tauri, TypeScript, and the stack most Tauri 2 apps use.
2. **Libraries:** Tailwind CSS 4 over the design's colour tokens
   (`app/src/styles.css`), Radix primitives for popovers and dialogs,
   Zustand for state, TanStack Virtual for the diff list, Shiki with its
   JavaScript regex engine for highlighting (the CSP allows no
   WebAssembly), `@fontsource-variable` for Geist and Geist Mono (bundled,
   not fetched), and the official Tauri plugins `dialog` (open a folder)
   and `clipboard-manager` (copy the review).
3. **Rust ↔ TypeScript types** are generated by `ts-rs` from the Rust
   types into `app/src/bindings/` when `cargo test` runs
   (`.cargo/config.toml`), and committed. A changed type is a changed
   binding in the same commit.
4. **Git is read through the `git` command line** (`crates/git`), not a
   library: no native dependency, worktrees and user config behave as in
   the terminal, and every call sets `GIT_OPTIONAL_LOCKS=0` so polling
   never contends with an agent committing.
5. **Persisted on the viewer's machine:** the webview's `localStorage`
   keys `diff-loop.recent` (recently opened folders) and `diff-loop.prefs`
   (instruction format and toggles). Both are read defensively; a bad
   value falls back to the default. Since ADR 0013 §4 only
   `diff-loop.recent` is read or written. Review comments are not
   persisted (superseded by ADR 0004).

## Consequences

- The review skill gains front-end stages (type check, build) as part of
  ADR 0006.
- Rendering depends on each platform's webview (WebKitGTK on Linux,
  WKWebView on macOS, WebView2 on Windows); each is checked before a
  release.
- `git` must be on the app's `PATH`, or found by the user's login shell
  (`docs/spec/diff-loop-git.md` Decision 8).
